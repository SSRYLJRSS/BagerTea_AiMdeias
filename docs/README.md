## 核心决策快照（已与老板确认）

- **底栏**：入库 | 素材库 | 打标（3 个纯文字按钮，居中）
- **左侧任务栏**：LR 式；素材库页=类型选择+标签树（2 级可折叠），设置页=分组导航
- **标签体系**：父子层级；EXIF 自身标签（只读）与 AI 分类标签（可自定义分类/上限）分离
- **AI 打标**：多中转站档案（profiles）自由切换；OpenAI 兼容 + Anthropic 双模式；云端 M1 交付，本地小模型 M2
- **缩略图**：双层策略；解码全局统一走 imaging.rs（内嵌预览优先，JPG 320px 实测 1.9ms）
- **删除**：P0 双策略（仅移出库 / 删除文件），二次确认
- **UI**：黑白灰高级感、苹果式简约动效、主 CTA 黑色实心
- **中文搜索**：FTS5 独立 fts_content 表 + 触发器 + cjk_bigram 逐字切分 + 短语 + ≤2 字 LIKE 兜底
- **技术栈**：Tauri 2 + Rust + SQLite FTS5 + React 19 + Zustand + Tailwind v4
