## 二、产品目标与设计哲学

**一句话定位**：一个为个人创作者打造的、极简克制的本地图片/视频素材数据库——「快入库、好检索、一键导出」。

**核心理念**：
1. **克制即体验**：全应用只有 3 个底栏入口（入库 / 素材库 / AI 打标），功能收拢，拒绝功能堆砌；底栏保持干净，上下文操作只在需要时浮现。
2. **本地优先**：数据、索引、标签、AI 打标全部本地完成，隐私默认安全，单机即可用。
3. **人机协作打标**：AI 打标是加速器而非替代者——默认手动批量确认，云端与本地双模可选，用户始终掌握标签控制权。
4. **达芬奇 × Notion 融合**：达芬奇底栏导航的「工具式直达」+ Notion 内容区的「极简留白」，界面安静、信息密度高而不杂乱。

## 四、需求池

优先级定义：**P0 = Must have（必须）**，**P1 = Should have（应该）**，**P2 = Nice to have（可以）**，**P3 = 远期规划**。

### P0 — 核心闭环（首版必须交付）

| ID | 需求 | 验收标准（简述） |
|---|---|---|
| R-01 | 本地入库（拖拽/文件选择） | 支持拖拽 + 文件选择器批量导入；图片与视频均可；**两段式确认：选文件先进入待入库清单（左侧任务栏显示图片/视频数量、总大小等统计 + 分库名称 + 批量改名选项），用户手动点「开始入库」才执行**；入库时建立索引并**秒级生成/提取占位缩略图**（JPEG 取 EXIF 缩略图、HEIC 取预览图、视频直接提取内嵌封面帧，PNG 等无内嵌的生成 256px 小图），入库后立即有预览；浏览到可见区时**按需生成高清缩略图（512px webp / 视频封面帧）并缓存**；重复文件可识别提示 |
| R-02 | 素材库网格浏览 | 极简网格展示；支持「全部/图片/视频/未打标」顶栏筛选；支持按标签树筛选；选中素材后顶部浮现上下文操作条（显示「已选中 N 项」+「AI 打标」「导出」按钮） |

### 5.4 关键交互细节

1. **底栏干净原则**：任何选中/操作状态都不改变底栏内容；上下文操作统一在内容区顶部浮现，避免底栏承载过多功能。
2. **选中态**（对标 Eagle/Bridge 竞品标准套件，v2.8 修订）：单击选中单张，**再单击已选中的（独占选中）则取消选择**；Ctrl+单击 切换加选/减选；Shift+单击 从锚点连续选择；**Ctrl+A 全选当前筛选结果全部**；**Ctrl+I 反选**；输入框聚焦时快捷键不拦截。选中后顶栏显示「已选中 N 项」；空白处点击/按 Esc 取消选中。
3. **选中操作条**（v2.8 修订）：顶栏内联，无特殊色框/填充按钮，统一文字按钮风格（删除用警示红文字）；「打标」单按钮悬停浮出「AI / 手动」两选项；全选/反选不入操作条。
4.5. **全屏查看器**（v2.9 新增）：双击网格卡片进入；不透明背景的新界面；大图/信息栏/胶片条三段；Alt+滚轮缩放、中键平移、右键按住放大；←→ 过片、Esc 退出、进场过渡动画。
5. **右键菜单**（v2.8 新增）：素材卡片/网格空白处接管右键，菜单含：**打标（悬停二级：AI / 手动）**/导出/删除/复制路径/打开所在文件夹（素材上）；全选/反选/取消选择（通用）。菜单随点随关，Esc 关闭；**删除无特殊色，靠二次确认弹窗兜底**。
3. **标签树导航**：树形列表，父标签可折叠/展开子标签；点击父标签连带筛选所有子标签素材，数量统计联动（父标签显示自身 + 所有子标签合计）；「未打标」为固定入口。
4. **删除双策略**：删除前必须弹窗选择「仅移出库（保留原文件）」或「删除文件」并确认；「删除文件」需二次确认并明确提示不可恢复。
5. **网盘导出**：百度走官方 OAuth 授权流程；夸克入口必须带「实验性」标注，并在操作前二次确认。

### 5.5 标签体系（v2.5 新增）

1. **两类标签泾渭分明**：
   - **EXIF 元信息**：相机/镜头型号、拍摄时间、ISO/光圈/快门/焦距——入库管线自动提取（kamadak-exif），**不进打标流**；打标页仅当前张下方一行只读小字，素材库详情可查。
   - **AI 分类标签**：AI 建议 + 人工确认的业务标签，按分类组织。
2. **分类 = 父标签（复用现有标签树，零新表）**：分类在设置页「标签分类」分组管理（新增/改名/删除）；每类可配专属提示词 hint 与 单选/多选；出厂默认 7 类：色彩风格/场景/人物/物体/氛围情绪/构图视角/光线。
3. **AI 建议结构化**：提示词按分类出活，返回 `{ "场景": ["公园"], "色彩风格": ["胶片感"] }`；确认时分类名建/复用父标签、建议词建/复用子标签——素材库标签树可按分类钻取筛选。
4. **确认粒度**：每张可整组采纳或按分类单独采纳/拒绝；手动加标签挂到所选分类下。

### 5.6 超级搜索（2026-08-25 新增，一期）

1. **入口**：双击底部「素材库」进入超级搜索；单击仍是普通素材库。双击必须取消待执行单击导航，不先闪切素材库。退出回到进入前页面，至少可回素材库。底栏在超级搜索页仍高亮「素材库」。
2. **定位**：独立素材检索工作台（非营销页），复用现有素材网格/预览/批量打标/导出/移动/删除；普通素材库状态独立，不互相污染。
3. **超级筛选维度**：类型（全部/图片/视频）、未打标、关键词、标签分面（同分面 OR，可切 ALL；父标签含后代或仅自身）、排除标签（默认含后代）、文件格式/MIME、宽度/高度/分辨率/宽高比、文件大小、拍摄/入库/修改时间、相机/镜头/ISO/光圈/快门/焦距、视频时长/编码、文件夹、排序。
4. **AI 智能搜**：自然语言 → `SearchIntent` →（后端白名单校验 + 标签解析）→ `ResolvedSearchQuery`。AI 不生成 SQL/tagId/assetId/分页/回收站；只生成文字标签与受控字段。默认**替换**当前条件，追加须用户明确选择。所有条件回填为可删芯片；warning 是可恢复状态非致命错误；删除条件只重查不重调 AI。
5. **协议**：`tag_facets.key` 是稳定机器协议（显示名可本地化不改 key）；`selection_mode/max_items` 以数据库为准，设置不存第二份；日期范围左闭右开、文件大小字节、视频时长毫秒、resolution=width×height、aspect_ratio=width/height；比较字段为 NULL 不命中；AI 搜索零数据库写入。
6. **明确不实现（一期）**：保存筛选、智能文件夹、评分、CLIP/embedding 视觉语义搜索、XMP/IPTC 双向写回、搜索专用 AI 档案、FTS 相关度复杂混合排序。

## 六、风险清单

| 风险 | 等级 | 影响 | 缓解措施 |
|---|---|---|---|
| **夸克网盘无官方 API，需模拟网页登录（cookie）走私有接口** | 高 | 接口随时可能变更/封禁；cookie 失效需重新登录；存在账号风控风险；功能不可持续 | ① 明确标注「实验性功能」并在导出前二次确认；② 独立封装适配层，接口变更时可快速隔离；③ cookie 加密本地存储，失效时给出明确引导重新绑定；④ 百度网盘为主路径，夸克仅作补充，不阻塞核心闭环 |
| **本地小模型体积/能力权衡** | 中 | 模型体积过大拖累安装体验与磁盘占用；模型过小打标准确率低，影响用户信任 | ① 应用内自动安装模型文件、可显示下载进度与磁盘占用；② 默认推荐平衡体积与准确率的模型档位，提供「轻量/标准/更强」选项（P2）；③ 本地与云端结果可对比，用户可混合使用 |
| **云端 API 成本** | 中 | 批量打标几万张素材会产生可观 token/调用费用，用户可能失控 | ① 打标前预估批次数量与估算消耗并提示；② 默认手动批量确认，避免无意识全量打标；③ 支持限流/批量上限设置；④ 本地模型作为零成本备选 |
| 万级素材性能（索引/虚拟滚动/缩略图） | 中 | 数据量大时搜索、滚动、缩略图加载可能变慢 | 虚拟滚动 + FTS5 索引 + **双层缩略图策略（占位图入库秒级生成/提取，高清图仅可见区按需生成并缓存）** + SQLite 查询优化；P0 验收标准绑定性能指标（搜索 ≤500ms、滚动流畅） |
| 视频抽帧/元数据提取兼容性 | 中 | 不同编码格式（H.264/H.265/ProRes 等）封面帧与播放兼容性差异 | 入库时直接提取内嵌封面帧作占位（提取失败降级为通用占位），高清封面帧按需生成；依赖系统/后端解码能力；元数据尽力而为 |
| AI 打标结果质量不稳定 | 中 | 标签建议可能不准确，污染标签体系 | 所有 AI 建议需用户确认后写入（默认）；提供撤销/清除 AI 标签能力（P2） |
| 数据安全（本地唯一副本） | 低-中 | 数据库/素材损坏即丢失，无云端备份 | 导出本地文件即天然备份路径；P2 增加素材库整体备份/迁移导出；「删除文件」策略对误删风险高，需二次确认兜底 |
