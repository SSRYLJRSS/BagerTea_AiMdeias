# 阶段 1 报告：入库连续选择与任务反馈

> 依据：《入库标签与素材库改造开发指导书-2026-08-25.md》第 4 节（阶段 1）
> 日期：2026-08-25

## 阶段
阶段 1——入库连续选择与任务反馈

## 目标
待入库清单支持连续添加文件/文件夹（追加保留旧清单）；入库任务即时反馈；页面只保留结果摘要；全局唯一进度条（底栏上方任务层）；阶段进度契约（后端只发 phase，前端按权重算整体）。

## 修改文件
- `src-tauri/src/services/importer.rs`：`ImportProgress` 重构为阶段模型（taskId/phase/phaseCurrent/phaseTotal/file/imported/duplicates/failed/message），新增 `ImportPhase` 枚举与 `queued/scanning/hashing/processing/previewing/done` 阶段上报；`collect_files` 支持扫描进度回调；`emit_done` 收尾；删除旧 `current/total` 全局计数（阶段切换不再倒退）。
- `src-tauri/src/commands/import_cmd.rs`：事件载荷随 `ImportProgress` 自动变化（无需改动，`app.emit("import://progress", p)` 透传）。
- `src/api/import.ts`：`ImportProgress` 接口更新为契约；新增 `ImportPhase` 类型。
- `src/stores/taskStore.ts`：`importOverall`（阶段权重 → 整体进度）、`upsertImport`（taskId 去重）、`markImportCancelling`；保留 export/ai 聚合；完成停留 1.5s。
- `src/components/layout/BottomBar.tsx`：任务条移至底栏上方任务层（bottom-14 + pb-2，距底栏 8px），`TaskRow` 单条摘要 + 不确定/确定进度条 + 失败文字/符号（不纯红），只由 `useTaskStore` 驱动。
- `src/pages/ImportPage.tsx`：移除页面级 `ProgressBar`，仅保留结果摘要（当前文件/成功/重复/失败/阶段）；新增 `chooseFolder`（目录选择器）；添加文件/文件夹/清空按钮经 props 下发 PendingList；运行中禁用添加/移除/清空；取消按钮调用 `cancelImport` + `markImportCancelling`。
- `src/components/import/PendingList.tsx`：固定动作头部新增添加文件/添加文件夹/清空清单 + 数量/大小，视图切换保留；按钮不直接 invoke，事件交上层页面。

## 新增文件
- `src/stores/taskStore.test.ts`（10 用例：阶段权重、不确定进度、taskId 隔离、失败文字、阶段切换不倒退）。
- `src/components/import/PendingList.test.tsx`（3 用例：动作头部存在、事件触发、运行中禁用）。
- `src-tauri/tests/services_integration.rs` 追加 `import_phase_progress_sequence`（queued→scanning→hashing→processing→previewing→done 相对次序 + 首尾阶段）。

## 删除文件
无。

## 前端协议变化
- `ImportProgress` 从 `{current,total,file}` 改为 `{taskId, phase, phaseCurrent, phaseTotal, file?, imported, duplicates, failed, message?}`。
- 新增 `ImportPhase` 联合类型。

## Rust 协议变化
- `services::importer::ImportProgress` 字段同前端契约；新增 `ImportPhase` 枚举（queued/scanning/hashing/processing/previewing/done），serialize 为 snake_case string。
- `import_paths` 回调闭包接收新 `ImportProgress`；`collect_files` 增扫描回调参数（`inspect_paths` 传 `|_|{}`）。

## 数据库迁移变化
无（不涉及 DB schema）。

## UI 变化
- 入库页不再绘制第二条进度条；改为结果摘要文本。
- 全局唯一任务进度条上移到底栏上方任务层，只由 taskStore 驱动。
- 待入库清单固定动作头部提供添加文件/文件夹/清空/数量大小/视图切换。
- 取消任务显示「取消中…」，失败任务显示文字 + ⚠ 符号 + 错误文案（不纯红）。

## 手动验收
- 待入库清单非空时，「+ 添加文件」「+ 添加文件夹」「清空」入口可见；按钮事件经页面层调用 `stage(paths)`，追加保留旧清单（按规范化路径去重）。
- 入库页只显示结果摘要（当前文件/成功/重复/失败/阶段），不显示第二条进度条。
- 底栏上方唯一全局进度条由 taskStore 驱动；阶段切换不倒退（权重单调）。
- 取消显示「取消中…」，完成后任务条停留 ~1.5s 消失；有失败项时显示文字 + ⚠。
- 入库期间素材库查询仍可执行（后端 spawn_blocking，不占库锁）。

## 已知问题

- `ollama_service_integration` 全量并行下偶发 localhost mock 失败（预存环境问题，与阶段 1 无关）。
