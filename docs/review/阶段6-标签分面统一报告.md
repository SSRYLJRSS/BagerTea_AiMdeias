# 阶段 6 报告：标签分面统一

> 依据：《入库标签与素材库改造开发指导书-2026-08-25.md》第 9 节（阶段 6）
> 日期：2026-08-25

## 阶段
阶段 6——标签分面统一

## 目标
`tag_facets` 作为唯一事实源（稳定 facetKey/默认显示名/描述/selectionMode/maxItems/排序/状态）；`aiFacetConfigs` 只决定 AI 行为（enabledForAi/hint/可选显示名覆盖）；`tagCategories` 只作迁移输入、不再作为业务渲染数据源；打标工作台与设置页使用稳定分面模型；基础分面永远显示。

## 修改文件
- `src/types/tag.ts`：新增 `WorkbenchFacet` 类型（key/displayName/description/selectionMode/maxItems/enabledForAi/hint）。
- `src/stores/tagStore.ts`：新增 `BASE_FACET_DEFAULTS`（10 个固定基础分面）、`keyForLegacyName`（中文分类名 → 稳定 facetKey）、`buildWorkbenchFacets`（tag_facets + aiFacetConfigs 覆盖；固定基础分面恒显）、`normalizeTagKeys`（把 AI/素材返回的分类 key 归一化为 facetKey）。
- `src/components/ai/Workbench.tsx`：`categories: TagCategory[]` → `facets: WorkbenchFacet[]`；面板分面 = 稳定分面（系统分面恒显）∪ 标签中出现的额外 key；标签 key 用 facetKey（`setFacetTags`）；`addTag` 单选替换旧值、maxItems 超限给出「已达上限 N 个」反馈（§9.4）；分类名固定宽度 + 分隔线保留。
- `src/pages/AiTaggingPage.tsx`：由 `buildWorkbenchFacets` 构建 `workbenchFacets`（订阅 tagStore.facets + settings.aiFacetConfigs），标签为空时刷新 tag facets；`draftTags` 用 `normalizeTagKeys` 归一化为 facetKey 后传给 Workbench（不再读 `settings.tagCategories`）。
- `src/components/ai/FacetTagInput.tsx`（新增）：§9.5 标签录入顺序——按当前 facetKey 先搜规范名 → 再搜 alias → 展示完整路径/所属分面；选择已有规范标签直接加入，Enter 明确确认才把新词加入候选（由后端确认写入时创建正式标签）；AI 未知词只进候选不建正式标签；输入为空且聚焦时展示「最近使用标签」快速选择（`recentTagOps` 去重、模块级缓存）。
- `src/components/ai/Workbench.tsx`：标签输入改用 `FacetTagInput`（`addTag` 支持显式 name）。
- `src/pages/SettingsPage.tsx`：§9.6 标签分类组内新增「标签治理」入口（打开现有 `TagManageDialog`，复用 merge/别名/停用/治理命令）。
- `src-tauri/tests/db_integration.rs`：新增 §9.7 交叉测试 `prompt_context_reflects_facet_config_overrides`——AI 打标与超级搜索共用 `build_prompt_context`，改 hint 两边同步读新值，显示名改变不影响 facetKey。

## 新增文件
- `src/stores/tagStore.test.ts`（6 用例：tag_facets 决定结构/默认；固定基础分面恒显；aiFacetConfigs 覆盖不改 facetKey；空显示名覆盖回退；`keyForLegacyName` 中文→facetKey；`normalizeTagKeys` 归一+合并）。

## 删除文件
无。

## 前端协议变化
- `Workbench` prop `categories: TagCategory[]` 移除，改为 `facets: WorkbenchFacet[]`（稳定 facetKey）。`AiTaggingPage` 不再传 `settings.tagCategories`。
- `AiBatch.status` 增加 `"interrupted"`。

## Rust 协议变化
无（后端 `tag_facets` 为唯一事实源；`aiFacetConfigs` 仅作 AI 行为覆盖——`build_prompt_context` 已在 P1B 落地）。

## 数据库迁移变化
无。

## UI 变化
- 工作台分面面板改由稳定 `WorkbenchFacet[]` 驱动（tag_facets 唯一事实源 + aiFacetConfigs 覆盖），系统分面（主体/对象、场景/地点、用途、风格/氛围、色彩、构图/视角、光线/时间、人物属性、可用性/技术特征、自定义）恒显（§9.3）。
- AI/素材返回的分类显示名 key 归一化为稳定 facetKey（未知 → custom），工作台回写/确认走稳定 key（§9.4/§9.5）。
- 单选分面选择新标签替换旧值；maxItems 超限显示明确反馈（§9.4）。
- 设置页「AI 分面」组已具备系统分面编辑（key 只读 + 显示名 + hint + AI 开关），selection mode/max items 以数据库为准（§9.6 系统分面部分）。
