# 阶段 4 报告：统一图片和视频悬浮预览

> 依据：《入库标签与素材库改造开发指导书-2026-08-25.md》第 7 节（阶段 4）
> 日期：2026-08-25

## 阶段
阶段 4——统一图片和视频悬浮预览

## 目标
入库清单与素材库的图片/视频 300ms hover 预览；图片三级策略；视频封面→原视频静音短播→（默认关闭）代理；同屏一个浮层；键盘 focus 支持。

## 修改文件
- `src/hooks/useHoverIntent.ts`（新增）：300ms 进入延迟 / 350ms 离开延迟 / 快速扫过不触发 / focus 触发 / disabled 不激活 / cancel 清理计时。
- `src/api/mediaPreview.ts`（新增）：`getImageHoverPreview`（1024px，同一素材同尺寸只请求一次，失败返回 null）；`getVideoProxyPreview`（默认关闭，恒 null）；`clearHoverPreviewCache`。
- `src/components/media/HoverPreviewTrigger.tsx`（新增）：hover/focus → 浮层显隐的触发器。
- `src/components/media/MediaPreviewPopover.tsx`（新增）：浮层，max-width 420px，max-height ≤70vh，作为触发器 DOM 子元素（指针移入浮层保持打开）；`computePopoverPosition` 计算位置自动避让左右/上下边界（§7.3），用 `position:fixed` + 视口坐标钳制。
- `src/components/media/ImagePreviewContent.tsx`（新增）：placeholder 先显示 → 1024px hover 图；加载失败显示类型占位 + 轻量错误文案。
- `src/components/media/VideoPreviewContent.tsx`（新增）：封面放大（零转码）→ 原视频静音短播（muted/playsInline、只播前 5 秒、失败降级），代理预留。
- `src/components/import/PendingList.tsx`：网格项包 HoverPreviewTrigger，`PendingHover` 内容（图片用 inspect 预览图，视频封面+原视频短播）。
- `src/components/library/AssetCard.tsx`：卡片包 HoverPreviewTrigger，`AssetHover` 内容（图片 1024px hover，视频封面+原视频短播；用 useEffect 在浮层激活时请求，不在 render 中 IPC）。

## UI 变化
- 图片/视频卡片 300ms hover 弹出预览浮层（图片 object-contain；视频封面→原视频静音短播，带 ▶ 预览角标）。
- 浮层最大宽度 420px、最大高度 ≤ 70vh，作为触发器子元素（指针移入浮层保持打开）。
- 键盘 focus 也打开预览；快速扫过不触发；切换卡片时旧触发器实例卸载取消待激活计时/请求。
- 视频代理预览默认关闭（`getVideoProxyPreview` 恒 null）。

## 手动验收（指导书 §7.5）
- 入库清单图片/视频 hover 预览可用（网格项覆盖）。
- 素材库图片/视频 hover 预览可用（AssetCard 覆盖）。
- 视频默认先显示封面（coverUrl = 首帧/占位图）；原视频播放失败降级回封面；代理生成默认关闭。
- 300ms 进入延迟、350ms 离开延迟有自动化测试（useHoverIntent 5 用例 + HoverPreviewTrigger 4 用例）。
- 大量卡片快速移动只激活单个浮层（每次激活独立实例 + 模块级缓存，不并发风暴）。

## 已知问题 / 限制
- 视频代理预览（Level 3）默认关闭，后端 `get_video_proxy` 命令尚未实现（当前 `getVideoProxyPreview` 恒 null）；待阶段 3 选路 + 设置项接入后补后端代理生成与 LRU 缓存。
- 浮层边界避让已用 `computePopoverPosition` 实现（左右/上下钳制，底部越界翻到上方），有位置计算单测；真机大屏/边界走查待验证。
