## 1. 一期最终目标

超级搜索一期是一个独立的素材检索工作台。

用户最终应能：

1. 从任意页面双击底部“素材库”进入超级搜索。
2. 使用类型、标签、元数据、时间、设备、视频属性和排序组合筛选。
3. 使用自然语言描述筛选条件。
4. 看到 AI 实际解析出来的条件。
5. 修改、删除或清空单个条件。
6. 在没有 AI 配置时完整使用手动筛选。
7. 继续使用现有素材网格、预览、批量打标、导出、移动和删除能力。
8. 不因为 AI 搜索而新增、修改或删除任何标签和素材数据。

一期明确不实现：

- 保存筛选。
- 智能文件夹。
- 评分。
- CLIP 或 embedding 视觉语义搜索。
- XMP/IPTC 双向写回。
- 搜索专用 AI 档案。
- FTS 相关度和时间的复杂混合排序，除非主线全部完成后仍有余量。

## 2. 不可违反的工程原则

### 2.1 模块边界

- commands 只负责参数校验、状态读取和调用 service/db。
- 网络请求放在 services。
- SQL 放在 db。
- 前端调用 Tauri command 必须经过 src/api。
- 网络请求期间不得持有数据库锁。
- 数据库锁必须短持有。
- 所有查询值使用参数绑定。
- AI 不生成 SQL。
- AI 不生成 tagId 或 assetId。
- AI 不控制 limit、offset、trashOnly。
- 未知字段和未知操作符必须拒绝，不能静默忽略。

### 2.2 标签边界

- tag_facets.key 是稳定机器协议。
- 分面显示名称可本地化，稳定 key 不可修改。
- 标签规范名、别名和路径可以参与搜索。
- 重命名和合并必须保留旧名称别名。
- AI 搜索中的未知标签只产生 warning。
- AI 搜索不能创建正式标签。
- 技术元数据不复制成标签。

### 2.3 查询语义

- 同一分面内默认 OR，可切换 ALL。
- 不同分面之间使用 AND。
- 父标签默认包含后代，可切换为仅当前节点。
- 排除标签默认包含后代。
- 比较字段为 NULL 时不命中。
- 超级搜索默认不查询回收站。
- 排序最后必须加入 a.id，保证分页稳定。
- AI 解析失败不能破坏当前查询状态。

### 2.4 AI 语义

- AI 输出 SearchIntent。
- 后端输出 ResolvedSearchQuery。
- 默认用 AI 结果替换当前条件。
- 追加条件必须由用户明确选择。
- AI 返回的所有条件都要回填到 UI。
- warning 是可恢复状态，不是致命错误。
- 删除条件后只重新执行查询，不重新调用 AI。

## P1A.4 Rust 校验

~~~text

  -> sort
~~~

必须校验：

- op 被该 key 支持。
- value 类型正确。

## P1A.5 SQL 白名单

显式编译：

~~~text
file_size + gte
  -> a.file_size >= ?

camera + contains
  -> lower(a.camera) LIKE lower(?) ESCAPE '\'

taken_at + between
  -> a.taken_at >= ? AND a.taken_at < ?

resolution + gte
  -> a.width IS NOT NULL
     AND a.height IS NOT NULL
     AND a.width * a.height >= ?

aspect_ratio + lte
  -> a.width IS NOT NULL
     AND a.height IS NOT NULL
     AND a.height != 0
     AND CAST(a.width AS REAL) / a.height <= ?
~~~

要求：

- 列名不能来自外部输入。
- op 不能直接拼接。
- 值全部参数绑定。
- contains 转义百分号、下划线和反斜杠。
- folder 使用内部路径处理。
- 日期范围左闭右开。
- 不使用 COALESCE 给缺失数值制造假值。
- aspect_ratio 是派生表达式，3 万行允许扫描，但文档注明暂不可用普通索引。

## P1A.6 FTS 改造

当前主链路：

~~~text
search_asset_ids
  -> Vec ID
  -> join(",")
  -> IN (...)
~~~

必须改成数据库内组合。

推荐抽象：

~~~rust
pub struct SearchPredicate {
    pub sql: String,
    pub params: Vec<Value>,
}
~~~

或等价的现有风格实现。

保持中文语义：

- 1 至 2 字：LIKE。
- 纯 CJK 3 字：FTS 短语。
- 纯 CJK 4 字以上：bigram AND。
- 混合文字：FTS 与 LIKE 的受控 OR。
- 标签规范名和别名继续参与。
- 用户输入仅作为参数或受控 MATCH 查询值。

list 和 list_ids 不得再获取全量 ID 后拼长 SQL。

search_asset_ids 可以保留作兼容工具，但不作为列表查询主链路。

rank 可选。没有完整测试时不要启用。
