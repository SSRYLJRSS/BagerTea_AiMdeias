按用户要求，施工前对指导书每个步骤做了破坏性风险评估（"这里修好、联动功能坏掉"的场景）：

|---|---|---|
| FB3-01 恒定槽位 | 可施工 | 槽位高度与 `AssetGridView.rowHeight` 必须同用 `HEIGHT_PX` 常量（已做到）；`ColorStrip` 空态 return null 的语义保留（查看器调用方依赖"安静消失"） |
| FB3-02 双排胶片条 | 可施工 | 纯布局改造，无数据联动；缩略图区 `min-w-0` 防按钮挤压（指导书 §4.2 要求） |

| FB3-06 顶部才展开 | 可施工（行为变更） | 旧语义"上滑累计即展开"是产品确认要改掉的行为；`useScrollDirection` 唯一调用方是 SuperSearchPage，无其他联动；测试断言按指导书第 4 条规则改写并注明新旧语义 |

## 3. 行为变更（新旧语义）

1. **FB3-06 折叠逻辑**：旧"上滑累计达阈值即展开" → 新"仅回到顶部区（scrollTop ≤ 48）自动展开；非顶部上滑保持收起"。用户点击「展开详细条件」仍立即展开。
2. **FB3-04 按钮语义**：「详情」→「信息」（职责不变：左属性栏开关）；新「全屏浏览」= 查看器级全屏。Esc：任一全屏中先退全屏，第二次 Esc 才关查看器。
3. **FB3-07 批大小**：默认 500→30；越界值（历史 500/0）读取时归一 30；UI 从自由输入改为 range 10–50；本地模型激活时显示只读说明。
4. **FB3-01 卡片几何**：开关打开时无色板素材也占色条高度（空槽）——这是修复错位的代价，换来的是行高恒定。
5. **FB3-05 双击判定**：`pointerdown e.detail===2` → 原生 `onDoubleClick`（行为语义不变，可靠性提升）。

## 5. 真机验收步骤（待用户在 `npm run tauri dev` 或打包程序执行）

指导书 §0.6 要求 Tauri/WebView2 真机验收，以下场景自动化测试无法覆盖：

1. **FB3-01**：冷启动素材库（一半素材有色板一半没有），开关打开，滚动到第 5/10/20 行——卡片不重叠、无递增空白；切页再回不位移。
2. **FB3-03**：打开高分辨率长视频——控制条可见、进度条可拖、±5s/倍速/静音/音量/全屏可用；`loadedmetadata` 前进度条禁用显示 `--:--`。
3. **FB3-04**：图片/视频分别点「全屏浏览」——胶片条/标签栏/属性栏/应用底栏消失；Esc 退出全屏（不关查看器），第二次 Esc 关查看器；退出后滚动位置/当前素材/侧栏开关恢复。
4. **FB3-05**：Alt+滚轮以指针为锚点缩放图片；双击 1x↔2x；播放器焦点内 ←→ 只 seek 不切素材。
5. **FB3-08**：设置 → 服务管理 → 对 agenes（`https://api.agnes-ai.cn/v1`）点「测试连接」——预期成功（密钥已配置且后端现在会带 Bearer）；对本地 Ollama 测试——预期成功（无鉴权 /models）。若仍失败，结果信息会指明是密钥/路径/网络哪一类问题。
6. **FB3-02**：>10 个素材时胶片条呈双排；窄窗口不溢出、宽窗口无空白列。
7. **FB3-06**：超级搜索下滚收起后，中段上滑保持收起，回顶部自动展开；点「展开详细条件」立即展开。
8. **FB3-10**：设置开启「查看器显示」后大图查看器标签栏上方出现色条；全屏时隐藏；悬停预览 300ms 原位播放。
